# Task: FizzBuzz with a Twist
Write a Python program that prints numbers from 1 to 50, but:

If a number is divisible by 3, print "Fizz" instead.
If a number is divisible by 5, print "Buzz" instead.
If a number is divisible by both 3 and 5, print "FizzBuzz" instead.
Otherwise, print the number itself.
Extra challenge: Store the results in a list and print the list at the end.
